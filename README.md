# ae3.pkg.net.ndm.client

"NDM NDSS Client" (per its own `project.inf` title) — a client library for the NDM/NDSS licensing system: `NdmLicenseStatic`/`NdmLicenseObject` (license lookup/representation), `NdmpLink`, `NdmUtilsStatic`. Connects this framework-level repo to the real `ndm` product namespace (see `magic-ndm-infra`/`magic-ndm-ndxs`) — this is the client side AE3-based services use to talk to it, not the NDSS service itself.
